# Elias Baby Website 💙

This is a GitHub Pages-ready baby keepsake website for Elias.

Included:
- Baby-blue watercolor background from the supplied artwork
- Elias details: 3 kg, 50 cm, 1 December 2025
- Two supplied Elias photos
- Home / Details / Letter / Photos / Our Story navigation
- Music button in the top-right

## Add the song
Put your MP3 in the `assets` folder and name it exactly:

`elias-song.mp3`

Then upload the whole project to GitHub. Clicking ♪ will play/pause the song.

## GitHub Pages
Repository → Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
